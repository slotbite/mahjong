## Síntesis

Integración de **Noto Emoji** (Google, Apache-2.0) en temas `selva`, `cozy`, `geek` y `acuario` de Memorice Cozy v2.0, reemplazando cartas Kenney.

**Cartas por tema:**
- `selva` (Selva tropical): 27 cartas, 62.5 KB
- `cozy` (Rincón cozy): 24 cartas, 51.3 KB
- `geek` (Pasatiempos geek): 24 cartas, 45.3 KB
- `acuario` (Acuario): 24 cartas, 55.4 KB

**Total:** 99 cartas en 4 temas, 615.9 KB de assets.

## Extensiones al pipeline

Ninguna extensión necesaria. El pipeline `tools/build-assets.mjs` ya soporta:
- Modo `vector` con `pixelate` (reducción + upscaling nearest)
- Lectura de crudos desde `assets/raw/<tema>/<cardId>.<ext>`
- Codificación WebP lossless/lossy automática
- Generación de dorsos recoloreados

**Scripts auxiliares creados (no commiteados):**
- `tools/update-noto-config.mjs` — actualizar config con Noto
- `tools/generate-contact-sheets.mjs` — generar hojas de contacto

## Cómo continuar

1. **Revisar hojas de contacto:** `doc/v2/themes-15/*.png`
2. **Probar en el juego:**
   ```bash
   cd .claude/worktrees/themes-15
   python -m http.server 8097 --bind 127.0.0.1 &
   # Abrir http://127.0.0.1:8097/ en navegador
   # Cambiar tema por consola: settings.set('themeId','acuario'); bus.emit('theme:load',{themeId:'acuario'})
   ```
3. **Commitear:**
   ```bash
   git add assets/src-config.json assets/themes assets/manifest.json CREDITS.md doc/v2/themes-15*
   git commit -m "feat(themes-15): temas selva, cozy, acuario y geek con Noto Emoji (Apache-2.0)"
   ```
